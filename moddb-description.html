Pin Matrix is a spreadsheet for your waypoints — every pin you own in one sortable, filterable table, edited a hundred at a time instead of one at a time on the map. Find the pin you meant to keep, retint a whole class of them in one pass, switch off the clutter without deleting anything, and hand a location to a friend in a click. Fully client-side: install it on your client and it works on any server, modded or not.

Where it installs Your client only. Nothing goes on the server, and nobody else needs it.
Game version Vintage Story 1.22.x — tested against every patch release, 1.22.0 through 1.22.7.
Other mods Tested alongside Waypointer, Translocator Paths, ProspectTogether, Boat Autopilot, Status HUD Continued and Tallybook — each on its own and all together, every release.
What it changes Your own waypoints, and only when you say so. Every bulk operation shows a before/after preview first, deletes go to a recycle bin, and the last one can be undone.
Opening it P with the world map open, or the Pin Matrix Editor button on the map. A rebindable hotkey is there too — it ships unbound.

Six filters, six questions

Filter The question it answers
Search What did I call that place, roughly?
Icon strip Where is every copper node I have marked?
Colour Which pins did I tint for this project?
Pinned only What am I carrying a screen-edge arrow for?
Show: all / visible / hidden What have I switched off, and is it still there?
Within N blocks What is near me right now?

They all compose — search inside one icon inside one colour inside 500 blocks — and every count you see respects the filters above it.

Pin sets — save a filter, get a map filter

Filter the table to whatever you like — one icon plus a search word, say — press Save as set..., give it a name, and it becomes a row in a panel down the right-hand side of the world map. Click the row and every pin it matches leaves the map at once; click again and they come back.

A set stores the question, not the answer. The filter runs again the moment you click it, so resin you marked this morning is covered by a set you made last week. Nothing anywhere stores a list of pins, so a set never quietly stops covering the things you have added since.

The panel is a drawer and it starts shut — a 16px pull against the map's edge, because the free space beside the map is only whatever your screen has left over. While any set is hiding pins the pull re-colours, so a filter you left switched on can never be invisible. Pins missing from your map with nothing on screen explaining why is the one thing this feature exists to prevent.

An interface that follows the screen it is on

Nothing in Vintage Story resizes a dialog. A window is a fixed number of pixels across, so on a screen half as wide it takes twice the share of it — and the only lever is the game's GUI scale, four clicks deep in Settings. Anyone who moves between a desk monitor and a remote session at a smaller resolution re-does that by hand every single time.

Switch on Fit interface scale to the screen and Pin Matrix re-derives it for you whenever the screen changes size. It measures from a reference — the scale you last chose and the screen you chose it on — so going to a smaller screen and back returns you to exactly the scale you started from, not somewhere near it. Set the scale yourself anywhere, including Vintage Story's own settings, and that becomes the new reference.

It is off by default. It writes one of the game's settings rather than one of ours, and a mod quietly resizing your entire interface had better be something you asked for.

What each part does

Click a heading to open it.

The table — sort it, filter it, and walk outward from where you stand

Every column sorts. Name, icon, colour, X, Y, Z, distance, pinned, and whether the pin is currently on your map — click a header to sort, click again to reverse.

The colour filter shows the colours. A dropdown of painted swatches with hex codes and live counts, sorted round the colour wheel with the greys first, listing only the colours your pins actually use. The counts follow your other filters, so you can see at a glance how many red pins are within 200 blocks.

The distance slider is an expanding search. Drag it out from off and your pins appear in growing rings around you — 10 blocks, 25, 50, and on up to 10,000. Or press Next pin and it widens the radius by exactly enough to reveal the next-nearest pin, one click at a time, until it tells you there is nothing further out. Both respect every other filter, so "the next copper node I haven't visited" is one button.

Coordinates read the way your HUD reads them — X and Z relative to spawn, Y absolute — so what is on screen is what you would type into chat.

Hide the clutter — switch pins off without deleting a thing

You do not need to see every copper node and resin tree all the time — only when you are going after copper or resin. Click the eye in a row's Vis column and that pin leaves the world map and the minimap, marker, hover text and screen-edge arrow with it, while staying exactly where it is: still on the server, still in the table, still searchable and editable, ready to come back.

In bulk, the way you do everything else here: filter to the copper icon, Select all filtered, Hide. It is instant in both directions — nothing is sent to the server, so there is no confirmation screen and no chat spam either way.

A Show: all / visible / hidden button filters the table by what is switched on, and a standing N hidden count sits by the page controls so you can never forget you have pins parked. Next pin and the distance slider walk past hidden pins rather than landing on things that are not on your map — switch to Show: hidden and they work on the hidden set instead.

Nothing is deleted to hide it. Your waypoints are untouched on the server: uninstall Pin Matrix and every hidden pin comes straight back.

Bulk editing — select, preview, confirm, undo

Select rows by clicking, shift-click for a range, or take the lot with Select all filtered. Then delete, set colour, set icon, pin, unpin or rename every one of them at once.

Every bulk operation is previewed before it runs — a before/after list of exactly which pins change and how, and a confirmation to get past. Renames preview the new titles; recolours show the old swatch beside the new one.

Deleted pins go to a recycle bin you can restore from, and Undo last bulk reverses the last operation whatever it was. If you would like a belt as well as braces, the config can write a full export before every mutating bulk operation.

Duplicates — fold them up, then clear them out

Flip Group duplicates and pins identical in every column collapse into a single row marked × N copies. Click the row to unfold it, tick it to select the whole group at once.

Fix duplicates is labelled with the live count and removes every extra copy through the usual preview and confirmation, always keeping one — and preferring to keep a copy that is still showing on your map, so tidying up can never leave you with an invisible survivor. It scans your whole list rather than the filtered view, so a filter cannot hide copies from the cleanup.

Fix same-spot pins is the other half of the job: pins that share a place and nothing else. One trader ends up carrying a pin you placed by hand, a leftover from whatever auto-marker you used before, and Pin Matrix's own — three different names, one cart. This finds those sets and offers them up, naming the survivor of each rather than only the condemned, because here the survivor is not interchangeable with what goes.

It is deliberately careful, since it can delete pins that genuinely differ. Pin Matrix's own trader marker is kept in preference while auto-marking is on. A trader camp survives intact — traders do stand together, but never two of the same kind, so pins naming different specialisations are never collapsed into each other however close they are. And grouping never chains: everything in a set is close to the pin that opened it, not merely to its nearest neighbour, so a line of pins cannot swallow a village.

One pin at a time — edit, move, find, share

Edit opens the familiar vanilla waypoint dialog. Move re-creates the pin at new coordinates. Map — or a double-click on the row — centres the world map on it.

Share sends a pin to chat or copies its command to the clipboard for Discord. Friends who also run Pin Matrix see a clickable add this waypoint link in chat, with the game's own confirmation prompt; everyone else still gets the location as plain readable text, and the copied command works for anyone you paste it to.

New pin creates one where you stand, or at coordinates you type.

Trader markers — optional: walk past a trader, get a waypoint

Off until you switch it on, on the Map options screen. Once on, walking past a trader drops a waypoint on them, coloured by what they deal in — nine specialisations, each colour editable with a live swatch and a per-row reset, using the vanilla trader-cart icon. The palette matches Waypointer's, so the same kind of trader reads as the same colour whichever mod put the marker there.

What it produces is ordinary waypoints, which is the whole point: they sort, filter, recolour, hide, bulk-rename, land in the recycle bin and export exactly like a pin you placed by hand. No parallel marker system, and switching the feature off later leaves nothing behind that the matrix cannot manage.

Two distances you control: how close you have to get before a trader is marked, and how near an existing trader pin has to be to count as "already marked" — kept deliberately loose, because traders wander around their cart.

Translocator paths — optional: only the hops you have actually made

Off until you switch it on. Step through a translocator and both pads get a waypoint, each named after the coordinates of the other end, with a line drawn between them on the world map. Nothing is ever recorded for a pad you merely walked past — that is the point of it.

Your paths follow your account, not your computer. A hop is described entirely by its two waypoints, and waypoints live on the server — so a network you map on one machine is simply there when you log in from another. No save file, no sync folder, no import step. Anyone you share one with can read where the pad goes even without this mod.

The hop you just took stands out, drawn in a bright high-contrast colour for twenty minutes (configurable, or off) before settling back to the normal one, so you can see at a glance which way you came. And if another tool already left you a pile of translocator markers, Adopt TL waypoints... converts them into Pin Matrix paths — previewed first, and only titles, icons and colours change.

Window layout — optional: snap the map screen's windows to a grid

Off until you switch it on, on the Map options screen — a button for a feature you never use is clutter on every map open. Once on, a Layout Zones (Z) button joins the map screen: press it and the screen fills with a grid. Drag any window by its title bar, drop it on a zone, and it snaps there — and comes back to the same place next time it opens.

You choose the grid. Anything from 1×1 to 50×50, split evenly across the screen: coarse for tidy halves and thirds, fine for precise placement on an ultrawide. Column and row numbers run along the edges so you can read a coordinate straight off the screen.

It refuses to bury your HUDs. Cells sitting under your coordinate readout, hotbar, chat or any mod's HUD are drawn red and will not take a drop, so a snapped window can never land on something you need to read. Untick Do not cover HUDs and the whole screen opens up — the grid itself does not move, so nothing you have already placed shifts.

Nominate a row as a tab strip and everything dropped on it spreads evenly across the full width like tabs, re-spacing as things come and go. The Pin Matrix buttons can join the strip, stack in a corner, or float separately — your choice.

Layouts survive your hardware. Zones are remembered as grid cells rather than pixel coordinates, so a new resolution, a different monitor or a nudge of the GUI-scale slider re-derives your layout instead of scattering windows off-screen. Reset layout puts everything back, and it is a chat command as well as a button — because a button inside a window that ended up somewhere unclickable is no help at all.

Import and export — a file you can keep, move or share

Export everything, or just your selection, to a file — then import it on another world, another character or another computer. Re-imports skip anything you already have, so running one twice is safe.

Keys

Key Does
P Open the editor, with the world map open
Z Show or hide the layout zones, with the world map open — once window layout is switched on
Double-click Centre the world map on that row's pin
unbound "Pin Matrix (waypoint manager)" under Settings → Controls, if you would rather have your own key

P and Z are not global binds — they exist only while the Pin Matrix buttons are on the map screen, so they cannot collide with anything in a long mod list, and they step aside the moment any text box has focus: chat, a waypoint name, or another mod's panel on the map. Either can be switched off entirely in the config.

What Pin Matrix will never do

  • Change anything without showing you first. Every bulk operation previews exactly what it will do and waits for a confirmation. Deletes are binned, the last operation is undoable, and an optional automatic backup can run before each one.
  • Delete a waypoint to hide it. Hiding is a display filter and nothing more — the pin stays on the server, untouched. Uninstall the mod and everything hidden comes straight back.
  • Touch waypoints that are not yours. Pins shared with you by group members are left out on purpose: the game only allows managing your own, and pretending otherwise would corrupt the list it edits by position.
  • Move one of your HUDs. The layout grid measures them and steers around them. It never repositions something that puts itself where it wants to be.
  • Claim a global key. P and Z live on the map screen only and stand down while you are typing. The one rebindable hotkey ships unbound, so nothing is taken from you on install.

Good to know

  • Because the mod is client-side, bulk operations go through the game's own chat commands — so the server echoes one "Ok, waypoint added" line per pin. Harmless, just chatty on a big job.
  • Which pins you have hidden is remembered per world on your own PC (a client-side mod has nowhere else to keep it), at ModData/pinmatrix/hidden-<world>.json. Copy that across if you want it on a second computer.
  • Window positions are written to the game's own clientsettings.json, the same place its movable dialogs already store theirs — so a laptop and a desktop keep independent layouts, and your windows stay put even without this mod.
  • Settings live in ModConfig/pinmatrix.json: rows per page, the bulk-operation throttle, recycle bin size, the auto-backup switch, the P and Z shortcuts, marker colours and distances, and the layout grid.
