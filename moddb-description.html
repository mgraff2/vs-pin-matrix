A spreadsheet for your waypoints. Pin Matrix puts every waypoint you own into one sortable, filterable table so you can find, tidy, retint, hide, and share them in bulk — instead of clicking pins one at a time on the map.

Fully client-side: install it locally and it works on any server, vanilla or modded. Nothing to install server-side.

Getting started

Open the world map (M) and click the Pin Matrix Editor button in the top-right corner, or just press P while the map is open. Prefer your own key? Bind one to "Pin Matrix (waypoint manager)" under Settings → Controls — it ships unbound.

The P shortcut steps aside whenever you are typing: if any text box has focus — chat, a waypoint name, or another mod's panel on the map screen — the letter goes into the box and Pin Matrix stays shut.

The table

  • Sort by name, icon, colour, X/Y/Z, distance, pinned state, or whether the pin is showing on the map — click any column header.
  • Filter with text search, an icon strip, a pinned-only toggle, and a colour dropdown that shows painted swatches with live counts — only colours your pins actually use.
  • Distance filter with a slider: drag it out from "off" and your pins appear in growing rings around you. The Next pin button widens the radius just enough to reveal the next-nearest pin — a one-button expanding search.
  • Coordinates display the same way your HUD does (X/Z relative to spawn), so what you see is what you'd say in chat.

Hide the clutter

You don't need to see every copper node and resin tree all the time — only when you're going after copper or resin. Switch a pin off with the eye in its Vis column and it disappears from the world map and the minimap, while staying right where it is: still on the server, still in the table, still searchable and editable, ready to switch back on.

  • Do it in bulk the same way you do everything else: filter to the copper icon, Select all filtered, Hide. Instant, both directions — nothing is sent to the server, so there's no confirmation screen and no chat spam.
  • A Show: all / visible / hidden button filters the table by what's switched on, working alongside every other filter, and a standing N hidden count keeps you honest.
  • Next pin and the distance slider skip hidden pins, so an expanding search doesn't keep landing on pins that aren't on your map.
  • Nothing is deleted to hide it. Your waypoints are untouched — uninstall Pin Matrix and every hidden pin comes straight back.

Bulk editing

  • Select rows by clicking, shift-click for ranges, or grab everything with Select all filtered.
  • Bulk delete, set colour, set icon, pin/unpin, and rename — every operation shows a before/after preview and asks for confirmation first.
  • Duplicate cleanup: a "Group duplicates" switch folds identical pins into single rows marked × N copies, and Fix duplicates removes every copy in one click, always keeping the original.
  • Deleted pins go to a recycle bin with restore, and the last bulk operation can be undone. Optional automatic backups before bulk operations are available in the config.

Per-pin actions

  • Edit opens the familiar vanilla waypoint dialog.
  • Move re-creates a pin at new coordinates.
  • Map (or double-clicking a row) centres the world map on the pin.
  • Share sends a pin to chat or copies its command to the clipboard for Discord. Friends who also run Pin Matrix get a clickable "add this waypoint" link in chat; everyone else still sees the plain text and can use the copied command.

Import / export

Export your waypoints to a file and import them elsewhere — re-imports skip anything you already have, so it's safe to run twice.

Good to know

  • Because the mod is client-side, bulk operations run through chat commands, so the server echoes one "Ok, waypoint added" style line per pin. Harmless, just chatty.
  • Waypoints shared with you by group members (owned by other players) are left out on purpose — the game only allows managing your own.
  • Which pins you have hidden is remembered per world on your own PC (the game gives a client-side mod nowhere else to keep it), so it doesn't follow you to another computer unless you copy ModData/pinmatrix/hidden-<world>.json across.
  • Settings live in ModConfig/pinmatrix.json: rows per page, bulk-operation throttle, recycle bin size, map-button position override, the P shortcut on/off, and more.
  • Tested for compatibility alongside Waypointer, Translocator Paths, ProspectTogether, Boat Autopilot, and Status HUD Continued — each on its own and all together.
  • Every release is run against real dedicated servers for 1.22.0 through 1.22.7 before it ships.
