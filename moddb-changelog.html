1.7.0

  • Fit interface scale to the screen. No window in Vintage Story resizes itself, so on a screen half as wide every dialog takes twice the share of it — and the only cure is the GUI scale setting, four clicks deep in Settings. Switch this on (Map options, off by default) and the scale is re-derived whenever the screen changes size. It measures from a reference: the scale you last set by hand and the screen you set it on, so going to a smaller screen and back returns you to exactly where you were rather than somewhere close. A scale you set yourself — including in Vintage Story's own settings — becomes the new reference.
  • An interface scale control on the layout screen, so you are not leaving the map to find it. Stepped with arrows rather than dragged: rescaling live under a dragging cursor makes the control you are aiming at move and change size while you aim.
  • Rescue off-screen. Windows remember absolute positions, so coming back on a smaller screen can leave one completely outside it with no title bar left to grab. One button — or .pinmatrix rescue — brings every one of them back into view.
  • Herty cup markers. With the Herty Cups mod installed, putting up a cup or taking resin from one drops a waypoint titled after the tree it is tapping. Both triggers are things you did, which is deliberate: a client is never told who placed a block, so marking the cups you have actually handled is the only way to get yours rather than every tap on the server.
  • Recently-used translocator paths crawl. The hop you just took is drawn as alternating bands that march from the pad you left towards the pad you arrived at, so the line shows the direction you travelled — something a flat line never could. Speed 0 leaves them as static stripes.
  • The layout tools are their own floating window. Show the zones and a small window appears with Layout Options, Rescan HUDs, Reset layout and Rescue off-screen. Drag it anywhere; it goes away with the zones. It deliberately cannot be snapped — the tools you use to arrange windows should not become another window to arrange.
  • The zone grid goes up to 50×50, and windows keep their relative place when you change it: a window four fifths of the way across a 20-wide grid is still four fifths of the way across a 40-wide one.
  • The Map options screen is a third shorter. Trader colours fold away, every colour and icon is a dropdown that draws the actual thing instead of spelling out a hex code, and the status readouts moved into tooltips on their own section headers.
  • The pin table gained page jumps — |<, <<, >>, >| for first, back ten, forward ten and last — and its colour and icon filters are now labelled and sorted with the most-used first.
  • Fixes: windows now snap in every button mode and the tab row accepts a drag; a wrapped warning no longer paints over the list beneath it; the layout screen no longer reports the grid size from one keystroke ago; and the close button on a layout title bar does something.

1.6.0

  • Pin sets — save a filter, get a map filter. Filter the table to whatever you like, press Save as set..., name it, and it becomes a row in a panel down the right of the world map. Click it to hide everything it matches; click again to bring it all back.
  • A set stores the question, not the answer. The filter is re-evaluated the moment you click, so resin you marked this morning is covered by a set you made last week. Nothing stores a list of pins.
  • The panel is a drawer, shut by default, parked against the map's right edge as a thin pull. It re-colours while any set is hiding pins, so a filter you left on can never be invisible — pins missing from the map with nothing explaining why is the one thing this must never do.
  • The editor is much less busy. The 24-per-row grid of every waypoint icon in the game is now a dropdown listing only the icons your pins actually use, each with a live count; six rarely-pressed buttons moved behind Tools...; and the explanatory paragraphs moved into tooltips.
  • The map's layer tab reads "Translocator paths" instead of the raw key it showed before.
  • The tab row is chosen by dragging, not by typing a row number, and that row now refuses other windows — one dropped there used to end up underneath the button bar, unclickable. .pinmatrix unsnap releases a single window instead of resetting the lot.
  • Also ships the 1.5.1 fix: hidden waypoints no longer flash back onto the map while you drag it.

1.5.0

  • Map windows layout — snap your map-screen windows to a grid. Switch it on in Map options and a Layout Zones (Z) button joins the map screen. Press it and the screen fills with a grid: drag any window by its title bar, release it on a zone, and its top-left corner snaps there. It stays put, and it comes back to the same place next time you open it.
  • You choose the grid. Anything from 1×1 to 20×20, split evenly across the screen — a coarse 3×2 for tidy halves and thirds, or a fine 15×10 lattice for precise placement on an ultrawide. Column and row numbers are drawn along the edges so you can read a coordinate straight off the screen.
  • It refuses to bury your HUDs. Cells sitting under your coordinate readout, hotbar, chat or any mod's HUD are drawn red and will not accept a drop, so a snapped window can never land on top of something you need to read. Untick Do not cover HUDs and the whole screen opens up — the grid itself does not move, so nothing already placed shifts. A threshold setting decides how much of a cell a HUD has to cover before it counts.
  • A tab strip, if you want one. Nominate any row and everything dropped on it spreads out evenly across the screen like tabs, re-spacing itself as things come and go. The column you drop on sets the order along the strip. The Pin Matrix buttons can join it, stack in a corner, or float separately.
  • Windows are moved, not resized — each is anchored by its top-left corner to the zone you drop it on and keeps its own size. The game has no notion of a resizable dialog, so stretching one would only leave its contents in the corner of a bigger frame.
  • Layouts survive your hardware. Zones are remembered as grid cells rather than pixel coordinates, so a new resolution, a different monitor or a nudge of the GUI-scale slider re-derives your layout instead of scattering windows off-screen. Settings are per machine, so a laptop and a desktop keep their own.
  • Reset layout on the options screen, and .pinmatrix resetlayout in chat. The chat version matters: if a window ever ends up somewhere you cannot click, a button inside that window is no help.
  • Auto-mark traders. Optional and off until you switch it on: walk past a trader and a waypoint appears on them, coloured by what they deal in — nine specialisations, each colour editable, with the vanilla trader-cart icon. They are ordinary waypoints, so everything the matrix already does works on them: sort, filter by colour, hide, bulk rename, recycle bin, export.
  • Translocator paths — but only the ones you have actually used. Optional and off until you switch it on. Step through a translocator and both pads get a waypoint, each named after the coordinates of the other end, with a line drawn between them on the map. Nothing is ever recorded for a pad you merely walked past.
  • Your paths follow your account, not your computer. A hop is described entirely by its two waypoints, and waypoints live on the server — so paths you record on one machine are simply there when you log in from another. No save file, no sync folder, no import step. Anyone you share a waypoint with can read where the pad goes even without this mod.
  • The hop you just took stands out. A freshly-used path draws in a bright high-contrast colour for 20 minutes (configurable, or off) and then settles back to the normal one, so you can see at a glance which way you came. Adopt TL waypoints... converts translocator markers left by another tool into Pin Matrix paths, previewed first.
  • New Map options screen gathers everything the mod can add to your map — trader markers, translocator paths, and the switch for the Layout Zones button — in three sections with the explanations on hover rather than filling the screen. Layout Options on the map screen configures the grid itself, and appears only while the zones are showing, since there is nothing to tune when you cannot see them.
  • Fix same-spot pins. A second cleanup, for pins that share a place and nothing else — one trader carrying a pin you placed by hand, a leftover from a previous auto-marker, and Pin Matrix's own, under three different names. Fix duplicates keeps its strict meaning; this one is separate because it can remove pins that genuinely differ, so it previews the survivor of every set as well as what goes. Pin Matrix's own trader marker is kept in preference while auto-marking is on, and a trader camp survives intact — traders stand together but never two of the same kind, so pins naming different specialisations are never collapsed into each other.
  • Fixed: Fix duplicates missed pins that looked identical. It compared positions far more finely than the table displays them, so two rows agreeing in every visible column could still refuse to group because their true positions differed by a fraction of a block. Positions are now compared exactly as shown.
  • No new keybinding. Z toggles the zones, but only on the map screen and only once window layout is switched on — like P, it is not a global bind and cannot collide with anything in a long mod list.

1.4.0 — hide waypoints without deleting them
  • Hide waypoints without deleting them. Requested by a player: "I don't need to know where every copper node or resin tree is all the time, only when I need copper or resin." A hidden pin disappears from the world map and the minimap — marker, hover text and pinned screen-edge arrow with it — while staying exactly where it is, and staying in the table where you can find it, edit it and switch it back on.
  • A Vis column with a clickable eye on every row: open eye means it is on the map, struck-through means it is not. Hidden rows are dimmed but still readable, and the column sorts like any other.
  • Hide and Show buttons work on your selection, so the whole job is one pass: filter to the copper icon, Select all filtered, Hide. It is instant in both directions — nothing is sent to the server, so there is no confirmation screen and no chat spam.
  • Show: all / visible / hidden filter button, working alongside search, icons, colour, pinned-only and distance. It starts on all, so hidden pins never quietly vanish from the table too, and a standing N hidden count sits by the page controls.
  • The distance tools skip hidden pins: Next pin and the radius slider walk past them rather than landing on pins that are not on your map. Switch to Show: hidden and they work on the hidden ones instead.
  • Nothing is ever deleted to hide it. Your waypoints stay on the server exactly as they were — uninstall the mod and every hidden pin comes straight back. Which pins are hidden is remembered per world on your own PC, so it does not follow you to another computer unless you copy ModData/pinmatrix/hidden-<world>.json across.
  • Fix duplicates now prefers to keep a copy that is still on the map, so tidying duplicates cannot leave you with an invisible survivor.
1.3.2 — typing in another mod's map panel no longer opens the editor
  • Fixed: typing into another mod's map-screen panel could open Pin Matrix. Reported against Boat Autopilot — naming a route in its route planner opened the editor on the p. The map button's P shortcut now stands aside whenever any text box has keyboard focus, so it applies to chat, waypoint names, and any other mod that puts an input on the map screen. Pressing P with the map itself focused still opens the editor, and the rebindable Settings → Controls hotkey was never affected.
  • New setting MapButtonShortcutKey (default on) turns the P shortcut off entirely, for anyone who would rather keep the key free. The fix above works without it.
  • Now verified against dedicated servers for every release from 1.22.0 to 1.22.7, solo and alongside each supported companion mod.
1.3.1 — a label that overran the table header
  • Fixed the "Group duplicates" label wrapping onto a second line and overrunning the table header. Refresh moved down to the utilities row next to the recycle bin to make room.
1.3.0 — duplicate cleanup and a colour filter that shows colours
  • Duplicate grouping and one-click cleanup. A Group duplicates switch folds pins that are identical in every column into a single row marked × N copies. Fix duplicates is labelled with the live count and removes every extra copy through the usual confirmation preview, always keeping the original. It scans your whole list, not just the filtered view, so a filter cannot leave copies behind.
  • The colour filter shows the colours. Painted swatches with hex and a live count, sorted round the colour wheel, listing only colours your pins actually use. Counts respond to your other filters.
  • Fixed an empty table on servers where you had not opened the map yet — the mod now asks for your waypoints itself instead of waiting for the map to do it.
  • Fixed a crash on opening the editor caused by waypoint icons whose art had not loaded yet. An icon that genuinely cannot be drawn now falls back to its name and stays usable.
